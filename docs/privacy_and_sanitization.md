# Privacy and Sanitization

This repository is a portfolio reconstruction, not a publication of production institutional work.

## Excluded
- Student names
- Banner/student IDs
- Internal person identifiers
- Student-level institutional extracts
- Hard-coded student exceptions
- Credentials and connection strings
- Original ACTS submission workbooks
- Production schema/table names
- Institution-specific exception comments that could identify a student

## Generalized
Production object names and local reporting conventions are replaced with descriptive generic names. The SQL preserves transferable techniques—CTEs, joins, aggregation, window functions, cohort construction, code mapping, and validation—without reproducing sensitive operational details.

## Synthetic data
Files under `data/synthetic/` are fabricated examples and do not represent real students.
