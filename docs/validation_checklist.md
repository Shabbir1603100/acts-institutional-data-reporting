# Validation Checklist

Before a reporting extract is considered complete:

- Confirm reporting-year and term parameters.
- Confirm cohort inclusion/exclusion rules.
- Confirm one row per required reporting entity.
- Check duplicate student keys.
- Validate categorical fields against allowed code domains.
- Validate GPA and test-score ranges.
- Confirm date windows for completers.
- Confirm enrollment/full-time dependencies.
- Confirm not-applicable versus unknown coding.
- Reconcile admissions and enrollment counts.
- Reconcile completer counts to an independent control total.
- Inspect financial-aid totals for unexpected negatives or duplication.
- Remove all temporary validation identifiers before external delivery.
