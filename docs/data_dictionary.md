# Portfolio Data Dictionary

## Undergraduate admissions sample

| Field | Description |
|---|---|
| student_key | Synthetic/de-identified portfolio identifier |
| race_eth | Reporting race/ethnicity code |
| sex | Reporting sex code |
| admission_status | Admission outcome indicator |
| admission_process | Admission process category |
| enrollment_status | Fall enrollment indicator |
| full_time | Full-time enrollment indicator |
| bachelor_seeking | Bachelor's-seeking indicator |
| sat_math | SAT Math score |
| sat_reading | SAT Reading/Writing score |
| sat_total | Combined SAT score |
| act_math | ACT Math score |
| act_english | ACT English score |
| act_composite | ACT Composite score |
| hs_gpa | Secondary-school GPA |
| family_income_band | Reporting income category |
| pell_eligible | Pell-eligibility indicator |
| parent_education | Parental college-attainment category |
| remedial_course | First-term remedial-course indicator |
| tuition_fees | Reportable tuition and fees |
